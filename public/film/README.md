# 🎓 EduLearn - Online Kurs Platformu

Modern, profesyonel ve animasyonlu online eğitim platformu. Vue 3 + Vite + Pinia ile geliştirildi.

## ✨ Özellikler

- 🎨 **Modern Tasarım**: Açık tema, turkuaz/beyaz, Udemy benzeri arayüz
- 🌍 **Çok Dilli**: Türkçe ve İngilizce desteği (anında geçiş)
- 📚 **100+ Kurs**: 9 kategoride zengin içerik
- 🎬 **Video Oynatıcı**: Kurs detayında entegre video player
- 🔐 **Login/Register**: Tam oturum yönetimi
- 💳 **Sepet & Ödeme**: 3D animasyonlu kart preview
- ⭐ **Yorum & Değerlendirme**: 5 yıldızlı sistem
- 🏆 **Sertifikalar**: PDF indirilebilir sertifika
- 👨‍🏫 **Eğitmen Sayfaları**: Detaylı profil sayfaları
- 🔍 **Arama & Filtreleme**: Kategori, seviye, fiyat
- 📱 **Responsive**: Tüm cihazlarda mükemmel
- 🎭 **Animasyonlar**: Smooth geçişler, hover efektleri

## 🚀 Kurulum

```bash
npm install
npm run dev      # Geliştirme modu (http://localhost:3000)
npm run build    # Üretim için derle
npm run preview  # Üretim önizleme
```

## 🗂️ Sayfalar

- `/` - Ana Sayfa (hero, kategoriler, popüler kurslar, testimonials)
- `/courses` - Tüm kurslar (filtre, sıralama, sayfalama)
- `/courses/:id` - Kurs detayı (4 sekme: hakkında, müfredat, eğitmen, yorumlar)
- `/category/:id` - Kategori sayfası
- `/instructors` - Eğitmenler listesi
- `/instructors/:id` - Eğitmen detayı + kursları
- `/my-courses` - Kurslarım (ilerleme çubukları)
- `/profile` - Profil sayfası (düzenleme + rozetler)
- `/cart` - Sepet
- `/checkout` - Ödeme sayfası (kart preview)
- `/login` - Giriş
- `/register` - Kayıt (şifre güçlülük göstergesi)
- `/certificates` - Sertifikalar
